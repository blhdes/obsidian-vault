# Servei Tècnic Integral M.G.

Client website MVP for a technical services company based in Catalonia (air conditioning, electricity, plumbing, heating, solar, EV charging).

## Project status

Active — MVP built, ready to show to client.

## Repo

- GitHub (private): `https://github.com/blhdes/servei-tecnic-mg`
- Local: `/Users/agomezu/Claude/servei-tecnic-mg/`

## Pages

- `index.html` — main landing page (hero, services, brands, projects, emergency, contact)
- `admin.html` — project management panel (add/edit/delete projects, mark as featured)
- `projectes.html` — public projects gallery with category filters and modal detail view

## Tech

Pure HTML/CSS/JS. No framework, no backend. Projects stored in `localStorage` via `assets/projects-api.js` — designed to be swapped for real API calls later without touching the UI.
