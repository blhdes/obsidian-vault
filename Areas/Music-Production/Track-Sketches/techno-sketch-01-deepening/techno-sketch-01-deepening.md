# 🎛 Techno Sketch 01 — Deepening Phase

> **This is the home base for the deepening phase of our first techno track sketch** — [[techno-sketch-01|Techno Sketch 01]] (130 BPM, A minor, early-90s techno).

## What "deepening" means

The skeleton is done — drums + bass + acid lead + 4 scenes (Intro / Build / Drop / Break) + filter sweep. Deepening = adding **one layer or effect per session** to give the track depth *before* we commit it to Arrangement and export.

Each step is its own numbered note in this folder. We go **in order, one per session** (decided 2026-06-01). Each step also bumps a path's % in the [[Roadmap]].
