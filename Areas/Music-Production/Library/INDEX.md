# Library — INDEX

Entry point to all production knowledge. One line per file. Keep it in sync.
**Techniques** = how to make something. **Devices** = what a device does. **Tools** = tooling.
Source tags: `[manual]` connector · `[live]` read from Live · `[ext]` external · `[ear]` tested in a track · `[?]` unverified (queued)

## Techniques
- [[techniques/kick]] — Kick from Operator (or Drift): click, body, tail; raw / hypnotic / industrial variants
- [[techniques/rumble]] — Rumble low end: kick → reverb → distortion → filter → sidechain
- [[techniques/sub-bass]] — Sub and bass lines that lock with the kick; syncopation, placement-only variations
- [[techniques/drum-grooves]] — Hats, swing (Groove Pool), perc layer, ghost notes, fills, polymeter, pattern archetypes
- [[techniques/acid]] — Acid lines with Drift: resonance, glide, accent, cutoff movement
- [[techniques/metallic-perc]] — Inharmonic FM perc and industrial clangs
- [[techniques/stabs-textures]] — Dissonant stabs, leads/motifs, pads, drones and evolving textures
- [[techniques/sidechain]] — Sidechain ducking and pad-level routing
- [[techniques/returns]] — Return-track templates: SPACE, DELAY, RUMBLE, CRUSH
- [[techniques/arrangement]] — Hypnotic/raw arrangement: subtraction, sections, risers/stutter builds, Session → Arrangement
- [[techniques/session-template]] — Track budget, naming, colors, gain staging
