# Session template

## Summary
A minimal track budget and naming scheme. Everything inside Live is in English.

## Core — track budget
| Track | Type | Color |
|---|---|---|
| KICK | MIDI (Operator) | Red |
| SUB | MIDI | Dark red |
| PERC | MIDI (Drum Rack / Operator) | Orange |
| HATS | MIDI (Drum Rack) | Yellow |
| STAB / LEAD / ACID | MIDI, one role per track | Blue |
| ATMOS | MIDI/Audio | Purple |
| FX / RISER | Audio/MIDI | Grey |
| Producer Pal | MIDI | **Never touch** |

Returns → [[techniques/returns]]. Groups: `DRUMS`, `MUSIC`, `FX`.

## Core — naming
- Tracks: UPPERCASE role (`KICK`, `ACID 2`)
- Clips: `ROLE_variant` (`KICK_main`, `HATS_busy`, `ACID_A_fill`)
- Scenes: `INTRO`, `GROOVE A`, `BREAK`, `PEAK`, `OUTRO`
- Macros: describe the effect (`Drive`, `Grit`, `Tail`, `Tension`)

## Core — gain
- Master peaks around −6 dBFS before any limiting. The kick is the reference.
- Use Utility for gain while building. Leave the faders for mixing.
