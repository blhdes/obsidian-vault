# Returns

## Summary
Space and parallel processing live on returns. Drums stay dry on their own tracks. Filter every return, because mud on a reverb return is the most common problem.

## Core
| Return | Chain | Use | Source |
|---|---|---|---|
| A-SPACE | Hybrid Reverb → EQ Eight (HP ~200 Hz, LP ~6 kHz) | Room/hall for perc and stabs | [start] |
| B-DELAY | Echo (synced, dotted or 1/8) → EQ Eight | Throws, dub echoes | [start] |
| C-RUMBLE | See [[techniques/rumble]] | Hypnotic low end | [start] |
| D-CRUSH | Drum Buss / Roar → Glue Compressor | Parallel drum destruction, blended under the dry drums | [start] |

## Gotchas
- Existing sets may use other names (`A-Reverb`, `B-Delay`). Keep what's there.
- Send levels may need to be set in the UI → [[tools/producer-pal]].
