# Operator

## Summary
An FM synth with 4 oscillators (A–D) arranged by algorithms, plus a filter, LFO and pitch envelope. It's the main tool for kicks, subs, FM perc and metallic stabs.

## Core
| Parameter | What it does | Source |
|---|---|---|
| Algorithm | How oscillators modulate each other (carriers vs modulators) | [?] |
| Oscillator waveform | Sine = pure. Other shapes add harmonics | [?] |
| Coarse / Fine ratio | Frequency ratio. Non-integer ratios = inharmonic, metallic | [?] |
| Fixed mode (`A Fix On `) | Oscillator at a fixed frequency, ignores note pitch | [live] |
| Pitch envelope | Sweeps pitch over time. Its amount and decay make the kick click/punch | [?] |
| Amp envelope (`Ae …`) | Per-oscillator level envelope. Sustain is in dB | [live] |

## Gotchas
- Parameter names with trailing spaces, dB sustain, algorithm labels → see [[tools/producer-pal]]. [live]
- A modulator's level controls FM depth (brightness). Too much makes it noisy fast. [?]
