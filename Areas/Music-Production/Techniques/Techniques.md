# Techniques

How to actually **make the parts** of a track. This is where the hands-on, "do this to get that sound" knowledge lives — kept as genre-neutral as possible, with a note when something is style-specific.

Building blocks we'll cover over time:
- **Drums** — kick/snare/hi-hat patterns, the four-on-the-floor beat, grooves
- **Bass** — basslines and how they lock with the kick
- **Melody / harmony** — leads, pads, simple chord progressions
- **Effects** — reverb, delay, filters, risers, transitions
- **Arrangement** — turning loops into intro → build → drop → outro

Each technique gets its own note (e.g. `four-on-the-floor-drums.md`). We learn one block at a time, then combine them in [[../Track-Sketches/Track-Sketches|Track-Sketches]].
