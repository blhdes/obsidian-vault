# Chorus-Ensemble Width

Merges two classic movement effects into one device: **Chorus** (thickens by mixing the dry signal with a subtly detuned, delayed copy) and **Ensemble** (the fuller/wider descendant, modeled on vintage string-machine chorus circuits — 3 voices instead of 1). A **Mode** switch picks between them.

## What it actually does

A short delay (milliseconds) is constantly, slightly modulated in time by an internal LFO. That tiny pitch wobble on the delayed copy, mixed back with the dry signal, reads as "thickness" or "shimmer" — it simulates several slightly-out-of-tune voices playing the same note at once, the way a room full of real string players never lands perfectly in unison.

This is a **different dimension of movement than Auto Filter**: Auto Filter moves the *cutoff* (brightness pulses); Chorus-Ensemble moves *pitch/time* (width/thickness). The two can layer without directly competing.

## Key controls

| Control | What it does |
|---|---|
| **Mode** | Classic Chorus (2 voices, tighter, mono-safer) vs. Ensemble (3 voices, wider/lusher) |
| **Rate** | Speed of the internal LFO wobble |
| **Amount** | Depth of the pitch/time modulation |
| **Width** | Stereo spread of the effect |
| **Feedback / High Pass** | Feedback re-feeds the delayed signal for a more resonant, metallic edge; High Pass keeps the effect off the low end |

## Starter recipe — STAB ([[../Track-Sketches/hardgroove-134|Hardgroove 134]])

- Mode: **Ensemble** for the fuller/wider version (Classic if a more mono-safe/subtle result is wanted).
- Rate slow-ish, Amount light — this is meant to *thicken*, not obviously "swirl" (that's [[phaser-flanger-sweep|Phaser-Flanger]]'s job).
- High Pass the wet signal so the chorusing doesn't muddy the STAB's low-mid body.
- A/B against bypass — the effect should be felt as width/richness, not heard as an obvious effect.

Exact knob layout can vary slightly by Live version — hover each knob's tooltip in the actual device to confirm current names.
