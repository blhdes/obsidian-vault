## How to update

- **New partial pull:** when a monthly note logs a release as `(X of Y)` / `(track N only)` and the folder is kept under its real album name (not `Singles/`) for more to join, add a row here.
- **Filled in more tracks:** update the Have/Missing columns; if it's now complete, delete the row (and drop the ✅ note in the monthly log if worth flagging).
- **Skip:** VA-comp single-track pulls and cases where the missing track is already owned under a different release — those aren't gaps.
