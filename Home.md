# 🏠 Home

Welcome to my vault. This is where I keep **ideas, dev insights, project phases, and things I learn while coding** — both as a personal research tool and a shared memory with Claude.

An Obsidian vault is just a folder of Markdown files. Notes are organized using the **PARA method**.

## Folders

| Folder | What goes here |
|---|---|
| `Inbox/` | Quick captures. Dump anything here, file it later. |
| `Projects/` | Active work with a defined outcome (e.g. Culla app). |
| `Areas/` | Ongoing responsibilities with no end date. |
| `Resources/` | Reference material & topics I'm learning (e.g. Swift). |
| `Archive/` | Finished or inactive items. Move here instead of deleting. |

## Conventions

- **Filenames:** kebab-case → `my-cool-idea.md`, `login-flow-bug.md`
- **Dates:** ISO format → `2026-04-24`
- **Tags:** inline with `#tag` or in YAML frontmatter
- **Frontmatter template** (paste at the top of any new note):
  ```yaml
  ---
  title: Short title
  date: 2026-04-24
  tags: [project-culla, idea]
  ---
  ```

## Talking to Claude

Just describe where it should go. Examples that work:

- _"Save this idea to Projects/Culla/Ideas/"_
- _"Write a dev-insight note about SwiftData migrations in Projects/Culla/Dev-Insights/"_
- _"Add this Swift snippet to Resources/Swift/"_
- _"Drop this into Inbox/ — I'll file it later"_
- _"Keep track of this in our Obsidian vault"_ → Claude will pick a sensible folder and ask if unsure.
